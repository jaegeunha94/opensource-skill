Senior Javascript Interview 학습 목록

  • Day 1 — JavaScript 실행 모델과 이벤트 루프 답변 프레임워크 — 코드 실행 순서를 예측하는 사고법
  • Day 2 — Execution Context와 Call Stack 심화 — Creation/Execution 단계, Hoisting, TDZ, 스택 오버플로우
  • Day 3 — Scope Chain과 Lexical Scoping — 스코프 체인 조회 규칙, 함수/블록 스코프, 섀도잉
  • Day 4 — Closure 심화 — 클로저의 실제 메모리 모델, 반복문 클로저 버그, 실무 활용 패턴
  • Day 5 — Prototype과 객체 모델 — Prototype chain 조회 알고리즘, `class`는 syntactic sugar, `Object.create`로 체인 직접 다루기
  • Day 6 — `this` 바인딩 규칙 — 4가지 바인딩 규칙과 우선순위, `call`/`apply`/`bind`, 화살표 함수의 `this` 예외
  • Day 7 — Module 시스템 — CommonJS vs ESM, 순환 참조 처리 차이, 트리쉐이킹이 ESM에서만 가능한 이유, 번들러 경계(interop/dual package hazard)
  • Day 8 — Event Loop 심화 — Microtask vs Macrotask, 큐 우선순위, `requestAnimationFrame`과 렌더링 파이프라인 타이밍
  • Day 9 — Promise의 상태 전이와 실패 전파
