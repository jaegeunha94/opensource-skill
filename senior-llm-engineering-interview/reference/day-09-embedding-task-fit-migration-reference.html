Day 9 · 빠른 참고

Embedding과 검색 판단 — 도메인 평가와 교체 비용

임베딩을 지식 저장이나 권한 판단으로 과장하지 않고 task-fit으로 선택한다.

핵심 판단 기준

  1. exact ID → 키 조회; 표현이 다른 의미 질문 → embedding 비교.
  2. 유사도는 사실/권한 확률이 아님.
  3. query/document prompt·normalization·버전 고정.
  4. 도메인·언어·부정/예외 gold와 지연·비용 동시 평가.
  5. 동일 dimension ≠ 동일 공간; 새 index와 재임베딩 검증.

복습용 용어

embedding
입력을 검색·비교에 쓰는 숫자 표현으로 변환한 결과.
asymmetric retrieval
짧은 질문과 긴 문서처럼 서로 다른 역할의 입력을 검색하는 방식.
hard negative
표면/주제가 비슷하지만 정답 근거가 아닌 문서.
vector space compatibility
query와 corpus 벡터가 같은 비교 의미를 가진다는 조건.
