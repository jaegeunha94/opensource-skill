Day 10 · 빠른 참고

종합 모의 면접 — 메모리 접근 증거로 개선안 고르기

Day 1~9의 캐시·분기·SIMD를 하나의 가설 검증에 적용한다.

핵심 판단 기준

  • 포인터 의존 → 지연 가설, 높은 바이트 처리량 → 대역폭 가설.
  • 대표 분포·같은 실행 조건에서 한 변경씩 비교한다.
  • 전체 개선 한도=1/((1-p)+p/s). 변환·유지 비용 포함.
  • CPU별 이벤트 지원과 전체 서비스 p99를 확인한다.

복습용 용어

Pointer chasing
현재 노드를 읽어야 다음 주소를 알 수 있는 접근 방식.
Memory-bound
메모리 접근이 실행 성능을 제한하는 상태; 지연과 대역폭 원인을 구분한다.
Amdahl의 법칙
일부 구간의 개선이 전체 실행 시간을 얼마나 줄일지 계산하는 관계.
