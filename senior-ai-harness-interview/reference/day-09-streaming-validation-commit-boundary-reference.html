Day 9 · 빠른 참고

Streaming과 Structured Output — 미완료 조각과 실행 경계

첫 조각을 빨리 보여주는 흐름과 검증된 도구 실행을 분리한다.

핵심 판단 기준

  1. 조각은 preview; 금액/외부 실행을 확정하지 않음.
  2. ID별 조립·buffer/시간 한도·정상 종료·stop reason 검사.
  3. schema → 업무 불변조건 → 권한/승인 → 멱등 실행.
  4. 생성 미완료와 외부 실행 결과 불명을 다른 상태로 복구.
  5. TTFT와 최종 완료·실패·취소 시간을 함께 측정.

복습용 용어

SSE
서버가 HTTP 응답에서 이름 있는 event를 순차로 전달하는 방식.
TTFT
첫 토큰/유용한 출력이 도착하기까지의 시간. 측정 정의를 합의해야 한다.
partial JSON
완성되지 않은 JSON 문자열 조각. 실행 가능한 인자로 취급하지 않는다.
commit boundary
검증 뒤 되돌리기 어려운 외부 효과를 시작하는 경계.
