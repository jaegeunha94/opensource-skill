Day 4 · 빠른 참고

프로젝트 구조와 패키징 — 소스 트리에서 설치 계약으로

Day 3의 예외 설계를 작은 패키지로 옮기고, 저장소 밖의 깨끗한 환경에서 wheel 설치를 확인한다.

핵심 판단 기준

  • src layout은 루트에서 소스를 우연히 import하는 경로를 줄인다.
  • build-system은 빌드 도구, project는 배포 메타데이터다.
  • 공개 API를 명시하고 Day 3의 도메인 예외·원인 연결을 유지한다.
  • 깨끗한 환경 + wheel 설치 + 저장소 밖 실행으로 artifact를 확인한다.

복습용 용어

Distribution
pip 같은 도구로 설치하는 이름·버전·파일 묶음.
Wheel
빌드된 설치 artifact로 사용하는 Python 배포 형식.
Build backend
pyproject의 선언에 따라 배포 artifact를 만드는 구현.
Editable install
개발 소스 변경을 설치 환경에 반영하는 방식; wheel 검증과 다르다.
