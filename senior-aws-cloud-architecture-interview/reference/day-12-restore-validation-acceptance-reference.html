Day 12 · 빠른 참고

DR 리허설 — 복구 검증 자동화와 사용자 전환 조건

복원 작업 성공과 서비스 복구 성공을 구분하고 RTO·RPO를 실제 증거로 확인한다.

핵심 판단 기준

  1. 성공 기준은 사용자 기능·정합성·단일 쓰기 주체까지 포함.
  2. RTO 시계 경계를 합의하고 전체 단계를 측정.
  3. RPO는 독립 확정 marker와 복구 시점으로 확인.
  4. 복원 job·검증 결과·전환 리허설의 증거를 구분.
  5. 격리 환경의 side effect와 잔여 자원을 통제.

복습용 용어

RTO
합의한 장애 시점부터 요구 서비스 복구까지 허용하는 시간.
RPO
복구 시점에서 허용하는 데이터 손실의 시간 범위.
restore testing
복구 지점에서 실제 자원을 복원해 복원 가능성을 시험하는 절차.
split brain
서로 조정되지 않은 여러 쓰기 주체가 활성화되어 데이터가 갈라지는 상태.
