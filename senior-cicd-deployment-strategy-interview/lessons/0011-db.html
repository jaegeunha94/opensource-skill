배포 중 데이터베이스 호환성과 롤백 경계

애플리케이션 artifact는 롤백할 수 있어도 데이터 변환은 같은 방식으로 되돌릴 수 없다. 배포 안전성은 버전 간 호환 창에 달려 있다.

오늘의 학습 결과: DB migration의 배포 순서, 관측 지표, 안전한 contract 시점을 설명한다

면접 질문

새 컬럼과 새 코드가 동시에 필요한 기능을 무중단 배포하고 장애 시 되돌리는 절차를 설명하세요.

실무 상황: API 서버가 rolling deploy로 교체되는 동안 구버전과 신버전이 동시에 DB를 사용한다. 테이블은 큰 편이고, 새 컬럼 backfill은 수십 분 걸린다.

왜 묻는가: 파이프라인 단계가 아니라 앱·스키마 호환성, 배포 중 상태, rollback의 현실적 한계를 설명하는지 본다.

전제 개념

배포 중에는 여러 버전의 코드가 동시에 실행될 수 있다. Expand 단계는 구 코드가 계속 동작하는 새 DB 구조를 먼저 추가하고, Contract는 모든 구 코드 사용이 끝난 후 오래된 구조를 제거한다.

rollback은 코드 버전만 되돌린다. 신버전이 새 형식으로 쓴 데이터를 구버전이 읽지 못하면 코드 rollback은 오히려 장애를 만든다.

답변 사고 순서

  1. 변경 분류: additive인지 destructive인지, DDL lock·rewrite·index build 비용을 조사한다.
  2. 확장 배포: 구 코드와 호환되는 schema를 먼저 배포하고 lock wait·replication lag를 본다.
  3. 코드 전개: 새 컬럼을 dual-read/write 또는 feature flag로 단계적으로 사용한다.
  4. 데이터 검증: backfill 누락·중복·오류율과 read parity를 확인한다.
  5. contract 승인: 구 버전·rollback 창·consumer가 없고 복구 대안이 검증된 후 제거한다.

케이스 풀이와 답변 예시

새 기능 출시를 feature flag로 분리하면 코드 배포와 사용자 노출 시점을 분리할 수 있다. 하지만 flag off가 destructive schema 변경을 되돌리지는 않으므로 DB 호환 설계가 여전히 필요하다.

먼저 변경이 additive인지와 해당 엔진의 lock 동작을 확인하겠습니다. nullable column과 인덱스를 먼저 안전하게 추가한 뒤 구·신 코드가 모두 읽을 수 있는 버전을 배포합니다. backfill은 제한된 batch로 진행하고 parity·replica lag가 기준을 통과하면 flag로 새 경로를 canary에 적용합니다. 오류 시 flag와 코드 rollback은 가능하게 두되, 구 컬럼 삭제는 구 버전 종료와 데이터 검증 이후 별도 release로 미루겠습니다.

답변에서 드러나는 점: 코드 배포, 기능 노출, 데이터 migration, 파괴적 schema 제거를 서로 다른 시점으로 다룬다.

Trade-off

선택얻는 점비용·위험
한 번에 schema+code 변경적은 배포 단계로 빠르게 끝난다.rolling deploy 중 호환되지 않는 인스턴스가 생기고 rollback이 어려워진다.
Expand-Contract호환 기간을 두고 영향 범위를 작게 관찰한다.dual path와 임시 컬럼·flag를 일정 기간 운영해야 한다.
온라인 인덱스/낮은 lock DDL가용성을 유지하며 변경할 수 있다.엔진·버전별 제한과 추가 I/O·복제 부하가 남는다.

흔한 오해

자동 롤백이 있으면 DB migration도 안전하게 되돌릴 수 있다.

데이터 쓰기와 외부 부작용은 되감기 어려울 수 있다. rollback은 앱 동작 복구일 뿐이며, 역변환·보상·forward fix를 사전에 정해야 한다.

직접 풀어보기

신버전이 새 컬럼에만 쓰기 시작한 후 p99 오류로 자동 롤백이 발동했습니다. 구버전이 누락 필드를 어떻게 처리할지와 다음 배포 전략을 말해 보세요.

예시 풀이와 피드백 보기

구버전이 null/미존재 값을 안전하게 처리하는 호환성 테스트가 먼저다. dual-write 기간을 연장하거나 forward fix를 선택하고, 데이터 복구 가능성을 확인한 뒤 destructive migration을 중단한다.
