Day 12 · 빠른 참고

Feature Flag — 점진 노출과 제거 수명주기

코드 배포·사용자 노출·데이터 변화·flag 제거를 다른 결정으로 관리한다.

핵심 판단 기준

  1. 목적·owner·기본값·만료/제거 목표를 등록.
  2. 안정적인 cohort와 실제 요청·매출 노출을 구분.
  3. stop 지표·판정 전파 지연·fallback을 측정.
  4. off는 새 진입 완화; 기존 부작용은 별도 처리.
  5. 코드 참조 제거 → 구버전 종료 확인 → flag archive.

복습용 용어

Feature Flag
실행 시 기능 경로를 선택하여 배포와 노출을 분리하는 제어.
stickiness
동일한 주체가 반복 평가에서 같은 배정을 유지하는 특성.
kill switch
장애 시 특정 기능을 제한해 영향을 완화하는 운영 제어.
stale flag
목적 수명이 지나 정리 여부를 검토해야 하는 flag.
