Day 12 · 빠른 참고

보안 회귀 테스트 — 인가 정책과 모든 실행 경로 검증

허용·거부 정책을 테스트 행렬로 옮기고, HTTP와 비동기 경로의 동일한 경계를 검증한다.

핵심 판단 기준

  • 정책 행렬 = 주체 × 자원 범위 × 행동 × 상태.
  • 허용 사례와 경계를 넘는 거부 사례를 함께 둔다.
  • unit 테스트는 규칙, integration 테스트는 실제 enforcement를 검증한다.
  • 거부 이후에도 데이터·파일·발송 부작용이 없음을 확인한다.

복습용 용어

정책 행렬
인가 조건 조합과 예상 허용/거부를 명시한 표.
enforcement
실제 실행 경로에 권한 판단을 적용하는 것.
기본 거부
명시적 허용 조건이 없으면 접근을 거부하는 정책.
TOCTOU
검사 시점과 사용 시점 사이 상태가 바뀌는 문제.
