Day 12 · 빠른 참고

eBPF/perf — 실행 시간과 대기 시간을 분리한 병목 진단

CPU 프로파일의 빈칸을 대기 스택으로 보완하고, 근거가 있는 제한된 진단을 설계한다.

핵심 판단 기준

  1. 요청 경과 시간과 CPU 실행 시간을 구분한다.
  2. 느린 요청의 스레드·시간대와 스택을 맞춘다.
  3. 정상 유휴·락·I/O·runnable 대기를 분리한다.
  4. 짧고 제한된 수집 뒤 같은 부하로 가설을 검증한다.

복습용 용어

on-CPU
CPU에서 실제로 실행 중인 시간.
off-CPU
CPU에서 실행하지 않는 시간. 측정 방식에 따라 대기 종류와 포함 범위를 확인한다.
futex
사용자 공간 동기화의 대기를 지원하는 커널 기제. 나타났다는 사실만으로 락 결함은 아니다.
샘플 분모
프로파일 비중을 계산한 전체 표본. 요청 경과 시간과 같지 않다.
