접근성·사용성 가드레일을 포함한 UX 실험 설계

Day 19의 지표를 협업 회의에서 쓸 수 있는 출시 판단 문장으로 바꾼다. 통계 방법론보다 용어와 합의 기준에 집중한다.

핵심 판단 기준

  • 주지표=개선 목표, 가드레일=허용할 수 없는 악화 관측.
  • 수용 기준은 사용자가 수행 가능한 행동으로 작성.
  • 계측 품질 → 필수 동선 → 가드레일 → 주지표 순서로 리뷰.
  • 평균 개선으로 특정 사용자군의 접근 실패를 덮지 않는다.

복습용 용어

Primary metric
실험이 개선하려는 핵심 결과의 지표.
Guardrail metric
악화시키면 안 되는 품질·피해를 관측하는 지표.
Acceptance criterion
구현을 수용할지 판단하는 구체적 검증 조건.
Stop condition
심각한 문제 때 노출을 중단하도록 미리 정한 조건.

다시 확인

  • W3C WCAG 2.2 — 키보드 trap과 포커스 등 접근성 수용 기준.
  • Microsoft Research 실험 지표 분류 — 주지표·가드레일·계측 품질 역할의 구별.
