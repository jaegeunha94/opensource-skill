Day 8 · 빠른 참고

Workers와 Redirect/Transform Rules — 요청 경로와 마이그레이션

주소 이동·내부 재작성·프로그래밍 로직을 구분하고 규칙 충돌을 요청 단위로 검증한다.

핵심 판단 기준

  1. 주소 이동은 Redirect, 내부 수정은 Transform, 코드가 필요한 분기는 Worker.
  2. Single Redirect → URL Rewrite, Single Redirect → Bulk Redirect의 현재 순서를 확인.
  3. Redirect 일치는 평가 종료; phase 내 조건 평가와 변경 누적을 혼동하지 않는다.
  4. Page Rules를 setting별 제품으로 이전하고 실제 URL·method·origin을 검증.

복습용 용어

Redirect
클라이언트에게 새 주소로 요청하도록 보내는 응답.
Rewrite
클라이언트 주소를 그대로 둔 채 내부 요청 정보를 바꾸는 처리.
phase
규칙 평가가 진행되는 제품별 처리 단계.
terminating action
일치 시 해당 처리 흐름을 종료하는 redirect·block 등의 행동.

다시 확인

  • Cloudflare — Redirects와 실행 순서 — 기능별 평가 순서와 종료 action
  • Cloudflare — Page Rules migration — setting별 신규 Rules 대응
  • Cloudflare — Workers Routes — Worker 호출 범위와 origin 연결
  • Cloudflare — Changelog — 작성 시점 변경 사항 확인
