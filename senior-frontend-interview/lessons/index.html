Senior Frontend Interview 학습 목록

  • Day 1 — 프론트엔드 시니어 인터뷰 답변 프레임워크와 브라우저 기반 사고
  • Day 2 — HTML/CSS 아키텍처와 크로스 브라우저 레이아웃 사고
  • Day 3 — 브라우저 렌더링 파이프라인 심화 (Critical Rendering Path, Reflow/Repaint, Layout Thrashing, Compositor)
  • Day 4 — JavaScript 실행 모델, 클로저와 메모리 누수 (콜스택/이벤트 루프/마이크로태스크, 클로저 기반 누수, 프로덕션 힙 스냅샷 진단)
  • Day 5 — 웹 접근성(A11y) 심화 (접근성 트리, WAI-ARIA, 키보드 인터랙션 모델, 스크린리더 대응, 프로덕션 접근성 감사 절차)
  • Day 6 — Web Vitals & 성능 예산 (LCP/INP/CLS 세부 진단, RUM vs Lab, p75 분포 사고, 성능 예산 설계와 CI 통합)
  • Day 7 — API 통합 & 네트워크 계층 (REST vs GraphQL 트레이드오프, HTTP/클라이언트 캐싱 계층, 멱등성과 재시도 전략, 오프라인 큐잉)
  • Day 8 — 상태/데이터 아키텍처 (클라이언트 상태 vs 서버 상태 분리 기준, 파생 상태와 상태 배치, 캐시 무효화 전략, 정규화된 캐시와 낙관적 동시성 제어)
  • Day 9 — React 렌더링 모델 — 상태 소유권과 비용 경계
