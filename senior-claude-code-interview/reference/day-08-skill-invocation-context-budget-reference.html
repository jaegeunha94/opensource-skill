Day 8 · 빠른 참고

Skills — 재사용 절차와 컨텍스트 비용의 설계

항상 필요한 저장소 규칙과 필요할 때 꺼내는 작업 절차를 분리하고, 호출 조건과 권한을 각각 검증한다.

핵심 판단 기준

  • 반복 산출물·실행 순서 → Skill, 항상 필요한 저장소 사실 → 프로젝트 규칙.
  • 자동 호출 여부, 사용자의 호출 가능 여부, 실제 도구 권한은 각각 검증한다.
  • 컨텍스트 예산은 설명 + 호출된 본문 + 실제 읽은 참조를 구별한다.
  • 성공 기준: 범위 적합성, 증거 확인, 미확인 표기, 불필요한 변경 없음.

복습용 용어

Skill
필요한 작업에서 호출하는 지침과 참조 자료의 묶음.
Progressive disclosure
목록에서 발견한 뒤 필요한 상세 자료를 단계적으로 읽는 방식.
disable-model-invocation
모델의 자동 호출을 막는 Claude Code 필드.
allowed-tools
호출 동안 도구 권한을 부여하는 설정이며 도구 전체를 제한하는 목록이 아니다.

다시 확인

  • Claude Code Skills — 호출 설정·컨텍스트·도구 권한의 현재 동작
  • Agent Skills specification — 표준 디렉터리와 메타데이터 형식
  • Claude Code changelog — 설치 버전에 따른 동작 변화 확인
