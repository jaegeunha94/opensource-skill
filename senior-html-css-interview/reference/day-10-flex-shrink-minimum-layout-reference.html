Flexbox 심화 — 축소 예산과 자동 최소 크기

Day 9 overflow를 이어서, 왜 flex: 1만으로 같은 폭과 축소를 보장할 수 없는지 계산한다.

핵심 판단 기준

  • 축소량은 shrink×basis의 가중치로 배분한다.
  • row는 min-width, column은 min-height와 부모 제약을 확인한다.
  • min-size 변경 뒤 wrap/ellipsis/scroll을 콘텐츠 의미에 맞춘다.
  • order는 DOM·탭 순서를 고쳐주지 않는다.

복습용 용어

Flex basis
유연한 공간 배분 이전 item의 기준 주축 크기.
Scaled shrink factor
부족 공간 배분에 쓰이는 shrink와 basis의 곱.
Automatic minimum size
콘텐츠 등에 근거해 자동 산정되는 item의 최소 크기.
