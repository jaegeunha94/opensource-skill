Day 10 · 빠른 참고

Subgraph와 Multi-agent — 상태 계약과 handoff 경계

역할 수를 늘리기 전에 입력·출력·공유 상태·도구 권한을 설계한다.

핵심 판단 기준

  1. 역할 분리 이유가 명확해야 agent 수를 늘린다.
  2. 공유 state key는 reducer, 다른 schema는 wrapper 입력/출력 매핑.
  3. private messages·thread 수명·checkpoint namespace를 설계.
  4. subagent 호출은 제어 유지, handoff는 역할 이동.
  5. tenant/도구 권한은 host에서 강제; subgraph가 sandbox는 아님.

복습용 용어

subgraph
다른 graph에서 node로 사용하는 재사용 가능한 graph.
wrapper
서로 다른 state schema를 명시적으로 매핑하는 경계 함수.
reducer
state 채널에 여러 업데이트가 올 때 병합 의미를 정하는 규칙.
handoff
처리 역할과 대화 제어를 다른 agent로 넘기는 방식.
