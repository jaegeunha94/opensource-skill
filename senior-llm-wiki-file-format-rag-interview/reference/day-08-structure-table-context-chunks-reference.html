Day 8 · 빠른 참고

문서 구조 기반 Semantic Chunking — 표의 의미와 근거 경계

표의 헤더·단위·각주를 보존하며 검색 단위와 답변 근거 단위를 분리한다.

핵심 판단 기준

  • 평문 분할 전에 구조 유실을 검사한다.
  • 표의 최소 근거 = 값+행/열 의미+단위+조건.
  • 검색 child와 답변 parent는 version·좌표·ACL로 연결.
  • context note는 보조 생성물; 원문 사실과 인용을 대신하지 않음.
  • 단일 조회·비교·예외 질문으로 coverage와 비용을 비교.

복습용 용어

structure-aware chunking
파싱한 제목·표·문단 등 문서 구조를 이용하는 분할.
semantic chunking
의미 유사도 변화 같은 신호로 내용 경계를 찾는 분할.
parent expansion
검색된 작은 단위를 관련 상위 구조로 확장해 맥락을 보충하는 처리.
contextual retrieval
검색용 chunk에 문서 맥락 설명을 보충하는 접근.

다시 확인

  • Unstructured — Chunking — element·제목·표 경계와 원본 metadata 복구
  • Anthropic — Contextual Retrieval — 검색 전 맥락 보충 접근의 원 자료
  • Unstructured — Releases — 표 분할·레이아웃 처리 변경 확인
